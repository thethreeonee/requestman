# 规则组侧栏

2026-09-26：用户选择方案 2，并要求整行浅灰 hover 背景及淡入淡出。初版静态稿见 [project-sidebar-hover-v1.png](project-sidebar-hover-v1.png)。随后按用户六项反馈修订：底部搜索与添加、统一行高、名称竖向对齐、双击展开、展开动画和纯图标网格。初版图保留作历史参考，当前行为以以下契约和源码为准。

## 布局与交互

- 保留规则组 → 请求修改两层。规则组有原生展开箭头和 SF Symbol，子项只显示名称。
- 规则树滚动区域延伸到标题栏背后，由 `NSScrollView` 自动调整顶部内容 inset，保证初始首行可见；向上滚动时使用系统标题栏的原生模糊效果，底部添加与搜索保持固定。
- macOS 26+ 将添加与搜索放入侧栏的原生底部附件，规则树铺满侧栏并滚动到操作栏背后，系统自动留出底部内容 inset；macOS 26.1+ 使用 `.soft` 滚动边缘效果。旧系统保留固定底部布局。
- 树形内容整体增加 8 pt 左侧留白，箭头、图标与名称同步右移；数量和操作栏仍贴合原有右侧位置。
- 文件夹与规则统一为 30 pt，不用额外行高制造分组间距；两级名称左边缘位于同一条竖线，文件夹通过展开箭头和图标表达层级。图标固定 16 × 16 pt，与名称相隔 8 pt；箭头、图标与文字垂直居中。
- 恢复原来的底部操作行：加号在左、搜索在右，高度和垂直中心一致；两侧留白 12 pt、控件间隔 10 pt、底部留白 10 pt。移除新增的顶部标题行。以上尺寸为本产品设计值，不是 Apple HIG 强制数值。
- 数量独立靠右对齐，24 pt 操作栏始终预留；更多按钮在 hover、选中或菜单打开时显示，按钮出现不挤动文字。长名称居中省略，悬停显示全文。
- 单击行只选择，双击文件夹名称或行内空白展开/收起；规则双击不折叠父文件夹。原生箭头仍可单击展开，左右键管理展开，上下键移动选择。双击箭头不叠加文件夹行的双击处理。折叠规则组不清除正在编辑的流程，会话内保留展开选择。搜索及新建后仍揭示新选中的流程。
- 规则组更多菜单支持“添加请求修改”，新请求直接归属该规则组。原有禁用、复制、重命名、图标、导出与删除入口保留。右键及键盘选中后可用的原生按钮提供替代入口。

## 拖拽排序

侧栏使用 `NSOutlineView` 原生拖拽会话、插入指示、组高亮与悬停展开。规则组只在根层排序，拖动时连同全部规则整体移动，不产生嵌套规则组。规则可以在组内排序，也可以移到其他组；放到组行上追加到组末，空组和收起的组均可接收，移动后展开目标组并选中移入的规则。组间空隙按前一组末尾处理，树顶空隙按第一组开头处理。

搜索期间依旧支持拖动：插到下一条可见规则之前，或追加到目标组全部规则末尾；隐藏规则保持相对顺序，整组移动包含隐藏规则。只接受当前侧栏的单项移动，不从外部粘贴板导入，也不把规则移出所有组。

`WorkspaceDocument.moveProject` / `moveWorkflow` 校验目标并调整同组向下移动的下标；宿主一次发布完整文档，复用自动保存和捕获配置更新。移动保留规则组、规则、匹配条件及步骤 ID 和启停状态；跨组后同步节点归属，后续编辑、菜单与导出使用新组。排序决定首个启用且匹配的规则，保存与重新载入保留顺序。

## 图标选择

图标预览将 SF Symbol 等比缩放到最长边 16 pt，居中绘制在 16 × 16 pt 的模板图像中。使用紧凑画布，避免透明边距被原生菜单一起缩放后导致图标过小；格子的留白与点击范围由原生 palette 提供。保留模板图像，避免裸 SF Symbol 被菜单按较大字号重新配置。

“修改图标”子菜单使用原生 `NSMenu.presentationStyle = .palette`，按六列、八行展示 48 个 SF Symbols 候选，覆盖文件、网络、设备、开发工具和通用标记。仅显示图标，不显示名称；中文名称保留在 tooltip 和辅助功能标签中。当前图标保持选中状态，跨行选择会清除其他行的选中标记。macOS 27 显式设置 `preferredImageVisibility = .visible`，避免系统菜单隐藏图标。旧系统不存在的 symbol 自动过滤。

## 展开收起动画

双击使用 `NSTableView.doubleAction`，通过 `NSOutlineView.animator()` 执行一次原生展开或收起，时长 180 ms；减少动态效果时直接切换。鼠标箭头和左右键保留 AppKit 原生行为。恢复初始化、筛选与新选中规则的展开状态时不附加动画。

展开按钮由 `NSOutlineView` 创建并管理，不替换按钮或叠加 SF Symbol 旋转。展开状态、箭头方向及行增删由同一个原生控件维护。移除自定义行位置、透明度动画与消失行快照，避免快速切换多个规则组时旧内容残留或重复显示。刷新数据时复用仍存在的节点对象，保留每个规则组的会话内展开状态。

## 启用与禁用

规则组只负责组织，不保存启用状态。菜单存在启用规则时显示“全部禁用”，否则显示“全部启用”；调用 `WorkflowProject.setWorkflowsEnabled` 批量写入每条规则的 `enabled`，并沿工作区保存通道持久化。匹配条件与请求／响应步骤各自的开关保持不变。

规则是否匹配、是否显示停用标记及是否置灰，仅取决于规则自身的 `enabled`。禁用规则的整行内容透明度设为 45%，包括名称与停用标记；选择和更多菜单仍可使用，规则组本身保持正常外观。旧配置中的组禁用在解码时一次性转换为每条规则禁用，重新保存不再写入组开关；之后可单独启用其中任意规则。

## 悬停动画

使用 AppKit `NSTableRowView` 的独立背景子层，动画不改变文字、图标、行尺寸或系统选中背景。仅未选中行显示低透明度语义灰色，深色模式随系统语义颜色适配。没有自定义玻璃、边框或阴影。

`CABasicAnimation(keyPath: "opacity")` 使用 ease-in-ease-out：移入 0.12 秒、移出 0.16 秒。先读取 presentation 的当前透明度，再禁用隐式动画、更新 model 终值，使用固定 animation key 替换旧动画，避免快速反转时跳回端点。不使用 `fillMode` 固定动画终态。

选择行时立即移除 hover；行从列表移除、窗口失焦或脱离窗口时也清理。移动鼠标、滚动、刷新布局时重新核对指针位置；菜单打开期间保留操作入口。启用“减少动态效果”时立即更新终值。
