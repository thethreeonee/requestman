- 标题栏中央用原生分段控件切换“请求修改 / 请求日志”，替换 Requestman 标题控件，删除内容区的重复导航行。

- 环境管理移到原生设置窗口，与“连接”并列；主窗口和设置共用同一环境模型，编辑与切换仍自动保存。

- 环境选择采用原生菜单 Picker，macOS 26 隐藏其工具栏共享玻璃背景，不叠加自定义玻璃或材质。

## 原生控件重构（2026-09-25）

- 项目导航使用 `NavigationSplitView`、`List(.sidebar)`、`DisclosureGroup` 和系统搜索栏。工作流行由 List 管理选择、焦点和键盘导航，不再使用按钮模拟列表行或手绘选中背景。
- 请求、响应两条流程分别使用可选择的原生 List，容器采用 GroupBox。保留步骤顺序、添加、停用状态和双向选择；移除自绘圆形编号、卡片、边框和选中色。
- 请求匹配字段使用 Form；步骤配置使用原生 Inspector 与分组 Form。检查器可关闭，选择步骤后重新显示；保留上移、下移、删除、模板和预览功能。
- 全局请求日志继续使用原生 Table，记录详情改用 Inspector 与 Form；暂停记录、清空、筛选和请求/响应详情保留。
- 设置中的环境管理使用原生导航列表和分组 Form；变量显示/隐藏、编辑、删除和快速切换保留。
- 移除显式 glass 按钮样式及内容上的自定义材质。只有环境选择保留隐藏共享工具栏背景的例外，以符合前述要求。

静态检查不能替代运行验收。人工检查：在项目列表和两条步骤列表中用方向键选择；切换项目、增删/重排步骤；收起并重新打开检查器；编辑环境；分别在最小窗口和默认窗口尺寸检查布局，并检查浅色、深色与减少透明度设置下的外观。

## Photos 标题栏参考（2026-09-25）

用户新增的参考图强调整条半透明模糊标题栏、单层玻璃操作分组与胶囊形分段选中态。本次采用系统 `ultraThinMaterial` 作为 macOS 26 标题栏背景，分段控件使用 AppKit `borderShape = .capsule`，由工具栏提供共享玻璃背景；控件仍按固有尺寸布局，不添加自绘边框、阴影或第二层 glassEffect。覆盖上文隐藏分段工具栏背景的方案。

保留左侧切换位置、共用侧栏和环境下拉框的普通原生样式；旧系统沿用默认外观。参考图下方是彩色照片，Requestman 的文字与纯色内容不会产生相同的彩色折射。此次只调整标题栏材质和控件轮廓，没有让正文忽略安全区来制造透色，滚动内容延伸及实际材质表现仍需运行检查。

实现依据：[Apple — Build an AppKit app with the new design](https://developer.apple.com/videos/play/wwdc2025/310/)。待验收项：活动/非活动窗口、浅色/深色、减少透明度、两页切换及单层胶囊轮廓；静态检查不代表已完成参考图的视觉对照。

标题栏高度随后从 `unifiedCompact` 调整为标准 `unified(showsTitle: false)`，增加系统提供的垂直空间，接近 Photos 参考的比例。保留控件尺寸、左右位置与材质，不通过额外空白视图撑高标题栏；最终高度由系统决定，待运行对照。

搜索入口移至标题栏右侧、设置按钮之前，两页共用同一个原生 `NSSearchField`，不再在项目侧栏或请求日志正文放置搜索框。请求修改按名称和 URL 前缀筛选，请求日志继续使用原有搜索逻辑；两页分别保存本窗口内的搜索条件。搜索框保持相同宽度，使用系统搜索和清除控件，不额外叠加玻璃背景。待运行核对中文输入、清除、两页切换后的条件恢复，以及最小窗口宽度下的工具栏布局。

底部状态栏归属右侧内容区，在 NavigationSplitView 的 detail 内与正文纵向排列；不再横跨整个窗口，左侧项目或记录详情栏延伸至底部。两页保持相同结构，侧栏收起时状态栏随内容区自然铺满。待运行核对侧栏拖动、收起和两页切换时的底部边界。

## 请求日志详情交互修订

请求日志不再使用左侧栏。进入日志页自动收起项目侧栏，默认不选中请求、不展开详情；点击日志行后，通过原生 Inspector 从右侧动画展开请求详情。关闭详情同时取消选中，允许再次点击同一请求打开；清空日志或选中记录被淘汰时详情随之关闭。切回请求修改恢复此前项目侧栏的显隐状态。此规则覆盖上文两页共用左侧栏展示详情的方案；待运行核对切页、选中、关闭及窗口缩放。

顶部切页和项目侧栏显隐的状态更新显式进入动画事务，侧栏与正文宽度使用 0.25 秒无回弹的平滑过渡；请求日志右侧详情的点击展开、关闭采用相同节奏。系统开启“减少动态效果”时取消这些位移动画。动画仅由导航和详情操作触发，不绑定捕获记录刷新；实际滑动效果及快速连续切换仍待运行验收。

## 侧栏底部工具修订

按最新参考图，将添加项目和请求修改搜索并排放在项目侧栏底部：左侧为圆形加号按钮，右侧为随侧栏宽度伸缩的原生 NSSearchField。macOS 26 的加号使用系统 glass 按钮样式，旧系统使用标准 bordered 样式；不自绘玻璃背景。工具区与列表分配独立高度，避免遮住最后一行。请求修改页不再显示标题栏搜索；无左侧栏的请求日志页继续使用标题栏右侧搜索。覆盖此前两页共用标题栏搜索的方案。待运行核对最窄侧栏、中文输入及清除、添加项目和侧栏收起后的布局。

用户运行截图确认：仅测量 SwiftUI 按钮高度再传给 NSSearchField，仍然存在可见边缘的高度差。现移除该测量补丁，底部整排改为同一个 AppKit 容器内的 NSButton 和 NSSearchField。以搜索框的原生高度为基准，使用 Auto Layout 对齐矩形约束令按钮等高、等宽并垂直居中；macOS 26 的按钮使用原生 glass bezel 与 circle 边框，保留等高约束并提供系统玻璃效果。加号继续打开“添加请求 / 添加项目”菜单，搜索、清除与禁用状态保留。标题栏搜索不受影响。源码检查已通过，可见边缘和输入文字的实际对齐尚待运行验证。

## 标题栏环境选择修订

环境切换使用独立的 `principal` 工具栏项，由系统放在标题栏中央，与右侧捕获操作分开布局。入口为单个文字按钮，显示当前环境名称或“无环境”；不嵌入下拉 Picker，不显示上下箭头或内层边框，macOS 26 只保留工具栏提供的一层原生胶囊背景。按钮文字区域最小宽度为 140 pt，随内容增长，不设固定最大宽度；允许水平方向压缩，由系统按左侧 Tab 和右侧操作之间的可用空间约束，空间不足时单行尾部截断。

点击后在按钮下方打开系统 Popover，参考 Xcode 的目标选择弹出层：顶部自动聚焦环境名称筛选框，下面列出“无环境”与命名环境；当前环境用蓝色高亮和勾选标记。点击整行切换并关闭，最多显示七行高度，更多环境滚动浏览；没有匹配时显示空结果提示。底部分隔线后的“管理环境…”直接打开设置中的环境管理页。Escape 或点击外部关闭弹出层，不更改选择；重新打开清空筛选。设置分页选择由工作区模型共享，仅作界面状态，环境切换继续使用原有保存逻辑。

AppKit 环境列表按布局后的实际行位置计算高度，包含系统侧栏样式的顶部留白；七项以内完整显示且不产生纵向溢出，超过七项才显示滚动条，不启用弹性回弹。隐藏窗口回归覆盖仅“无环境”、七项、八项及滚动后筛选缩短列表。

依据 [Apple principal](https://developer.apple.com/documentation/swiftui/toolbaritemplacement/principal)。待运行核对两种页面、侧栏展开/收起、最小窗口宽度、长环境名称、筛选/切换/关闭，以及设置窗口首次打开和已打开时的环境管理跳转。

## 全 AppKit 实现（2026-09-26）
